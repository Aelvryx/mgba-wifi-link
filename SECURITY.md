# Security policy

## Supported versions

Only the newest published prerelease and current `master` receive fork-specific
security fixes. Older experimental builds should be upgraded rather than
patched in place.

## Reporting a vulnerability

Use GitHub's private **Security → Report a vulnerability** flow for a suspected
security issue in this fork. Please include the affected release or commit,
platform, impact, and a minimal reproduction that contains no commercial ROM,
BIOS, save, credential, address, or other private data.

Do not open a public issue for an unpatched vulnerability. General mGBA issues
that are unrelated to this fork should be reported to the upstream project.

This experimental local-network feature is not designed for hostile or
untrusted peers. Security reports are still welcome, especially for packet
decoding, bounded allocation, callback lifetime, and artifact provenance.
