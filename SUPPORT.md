# Support and issue routing

Use this repository for the Wi-Fi link fork: Netpacket connection, replicated
Multi-Pak behaviour, supported builds, installation, latency, compatibility,
and fork release tooling.

Use [upstream mGBA](https://github.com/mgba-emu/mgba) for an emulator issue that
also reproduces in an unmodified upstream build without this fork's network
runtime.

Before filing here, collect:

- fork release or full commit;
- core SHA-256 when using an unpublished build;
- RetroArch version and platform;
- host/client roles and network topology;
- game title and region/revision identity without uploading the ROM;
- exact steps and the last visible message;
- both endpoint logs when a connection or divergence fails.

Do not upload commercial ROMs, BIOS files, copyrighted extracts, private save
data, IP addresses, or controller-input histories. Sanitized logs and fixture
reproductions are preferred.

Questions and compatibility reports are welcome through the issue forms.
